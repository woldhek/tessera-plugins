# Task List

A Tessera plugin that displays and manages Home Assistant task lists (`todo` domain entities).

## Features

- View active and completed tasks directly on your Tessera touch tile.
- Toggle task status between completed and pending.
- Automatically syncs with Home Assistant `todo` entities.

## Setup

1. Add the plugin to a screen in Tessera.
2. In Layout, place the **Tasks** tile from the plugin library.
3. In the inspector, select your Home Assistant `todo` entity under **Todo Entity**.
